# Трамвайное бюро

За одну смену в Приморске нужно доставить 64 пассажира. Жители выбирают между прогулкой и трамваем с учётом тарифа, ожидания и пересадок. Утром растёт спрос на поездки к вокзалу, а вечером горожане возвращаются домой. [Играть в браузере](https://troyan-dy.github.io/tramway-bureau/)

### Первая смена

1. На старте один вагон ходит между Старым городом и Рынком. Пока часы стоят, продлите линию до Вокзала и подтвердите стоимость строительства.
2. Купите второй вагон и запустите время. Слой «Потоки» и вкладка «Спрос» помогут увидеть, где люди ждут и куда едут.
3. Рядом с часами можно ускорить смену. В 22:00 бюро подведёт итоги. Выберите ту же карту для сравнения решений или другой район для новой партии.

У каждого района есть необязательное поручение. Его можно выполнить, продолжая работать над общей целью смены.

Смена сохраняется автоматически в браузере. В меню можно скачать сохранение и перенести его на другое устройство.

### Локальный запуск

Готовый `dist/index.html` открывается двойным щелчком и работает офлайн. Чтобы собрать его из исходников, используйте Node.js 24 и npm.

```sh
npm ci
npm test
npm run build
npm start
```

Локальный сервер отдаёт игру по адресу [127.0.0.1:18740](http://127.0.0.1:18740/). В сборку входят карта, код, шрифты Inter и PT Serif и тексты их лицензий SIL Open Font License 1.1. [Inter](assets/inter-LICENSE.txt) · [PT Serif](assets/ptserif-LICENSE.txt)
